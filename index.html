1919coin (YJU)

CPU で掘れる、約10分に1ブロックの小さなチェーン。

1919coin とは

1919coin は、Bitcoin Core v30.4 をベースに Proof of Work を RandomX に 差し替えた実験的な暗号通貨です。専用マシン（ASIC）ではなく、普通のパソコンの CPU で マイニングできることを目指しています。

プレマインはありません。ブロック報酬は 10 YJU から始まり、1,050,000 ブロックごとに 半減します。最大供給量は 21,000,000 YJU です。

仕様

単位YJU（補助単位: mYJU / µYJU / sat）
ベースBitcoin Core v30.4 フォーク
PoWRandomX（CPU フレンドリー）
ブロック間隔約600秒（10分、難易度は毎ブロック調整）
ブロック報酬10 YJU
半減期1,050,000 ブロック
最大供給量21,000,000 YJU
プレマインなし
アドレス形式iku1...（bech32）/ Y...（P2PKH）
ポートP2P 11451 / RPC 11450

ネットワークへの接続

クライアントにはシードが組み込まれています。起動すれば自動的に ネットワークへ接続します。

ソフトウェアは Windows 版（GUI / CLI）と Android 版ノードアプリがあります。 Android 版は試験的な提供で、動作の保証はありません。
