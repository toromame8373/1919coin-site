# 1919coin-site

1919coin (YJU) の紹介サイトです。静的な HTML だけのページです。

## ファイル

- `index.html` — ページ本体
- `icon.png` — コインの画像（ページから参照）

## 公開方法（Cloudflare Pages）

1. Cloudflare Pages でプロジェクトを作成し、この GitHub リポジトリを接続する
2. ビルド設定はなし（フレームワークなし、出力ディレクトリはルート）でデプロイ
3. カスタムドメインに `1919coin.f5.si` を割り当てる

GitHub 上で `index.html` を編集してコミットすれば、Pages が自動で再公開します。
